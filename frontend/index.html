Alert rules

Edit the JSON list. Supported types: level and ma_cross.
Amazon instrument IDs look like AMZ-P00014; Online Retail IDs look like OR-85123A. Use exact IDs from the selected dataset.

Rule logic

Level / belowCrosses from ≥ to <
Level / aboveCrosses from ≤ to >
MA crossoverShort crosses long
Warm-upFull windows only
ImportantAlerts trigger on crossing events, not every day the price remains on one side. Moving averages use each instrument's date-sorted daily prices.

Import price data

Upload a standard price CSV, the provided Amazon CSV, or the provided Online Retail Excel workbook.

Run from a clean download

1. Install Python 3.10 or newer.

2. Run pip install -r requirements.txt.

3. Run python app.py and open http://127.0.0.1:8000.

4. Assessment CLI: python alerts.py data/prices.csv rules.json.
